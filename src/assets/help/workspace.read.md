# Workspace Team Management (Read Access)

View your workspace team information, member roles, and workspace settings with read-only access.

## Team Overview

### Workspace Information
View key details about your current workspace:
- **Workspace Name**: The display name of your workspace
- **Creation Date**: When the workspace was established
- **Member Count**: Total number of team members
- **Active Users**: Currently active workspace members

### Team Members List
Access comprehensive information about all workspace members:

#### Member Information Display
- **Name and Email**: Full contact information for each member
- **Role Assignment**: Current role and permission level
- **Join Date**: When the member was added to the workspace
- **Last Activity**: Most recent workspace interaction
- **Status**: Active, inactive, or pending invitation status

#### Role Descriptions
Understanding different workspace roles:
- **Admin**: Full workspace management permissions
- **Manager**: Team and content management access
- **Analyst**: Core screening and analysis permissions
- **Viewer**: Read-only access to screening results
- **Guest**: Limited access to specific shared content

## Workspace Settings View

### Configuration Overview
Review current workspace configuration:

#### Feature Access
- **Available Modules**: Enabled features and capabilities
- **Integration Status**: Connected external services
- **Workflow Configuration**: Active screening workflows
- **Compliance Settings**: Regulatory and policy configurations

#### Usage Statistics
- **Screening Volume**: Number of completed screenings
- **Active Workflows**: Currently running processes
- **Storage Usage**: Data consumption metrics
- **API Usage**: External service utilization

## Understanding Permissions

### Your Access Level
With workspace read access, you can:
- ✅ View all team member information
- ✅ See workspace configuration and settings
- ✅ Access usage statistics and reports
- ✅ Review role assignments and permissions
- ❌ Cannot modify team member roles
- ❌ Cannot add or remove team members
- ❌ Cannot change workspace settings

### Permission Hierarchy
Understanding the permission structure:
1. **Workspace Admin**: Full management control
2. **Workspace Write**: Team management capabilities
3. **Workspace Read**: View-only access (your level)
4. **Feature-Specific**: Module-based permissions

## Requesting Changes

### When You Need Modifications
If you need changes that require write permissions:

#### Team Changes
- **New Members**: Request admin to add team members
- **Role Updates**: Ask for permission level adjustments
- **Access Modifications**: Request feature access changes

#### Workspace Settings
- **Configuration Changes**: Request setting modifications
- **New Integrations**: Ask for external service connections
- **Feature Activation**: Request additional module access

### Request Process
1. **Identify Need**: Clearly define what changes are required
2. **Contact Admin**: Reach out to workspace administrators
3. **Provide Justification**: Explain business need for the change
4. **Follow Up**: Track request status and implementation

## Best Practices

### Information Management
- **Stay Informed**: Regularly review team changes and updates
- **Documentation**: Keep personal notes on team expertise and contacts
- **Communication**: Maintain awareness of team structure changes

### Security Awareness
- **Access Monitoring**: Be aware of who has access to what information
- **Change Notifications**: Note when permissions or team structure changes
- **Compliance**: Understand data access and sharing restrictions
