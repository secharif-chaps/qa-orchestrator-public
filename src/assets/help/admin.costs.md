# Cost Analysis Dashboard

The cost analysis dashboard provides comprehensive tracking of your Dify workflow expenses, helping you monitor and optimize your platform usage.

## Features

### Overview Dashboard
- **Total Costs**: View aggregated costs across all tasks and workflows
- **Cost Trends**: Monitor spending patterns over time with interactive charts
- **Budget Alerts**: Set up notifications when approaching spending thresholds

### Task-level Analysis
- **Individual Task Costs**: Drill down into specific screening tasks
- **Performance Metrics**: Analyze cost per successful screening
- **Resource Utilization**: Track efficiency of different workflow components

### Detailed Cost Breakdown
Each task provides granular cost information:

#### LLM Costs
- **Model Usage**: Costs by AI model (GPT-4, Claude, etc.)
- **Token Consumption**: Input and output token costs
- **Request Volume**: Number of API calls and their costs

#### External API Costs
- **Third-party Services**: Costs from integrated external APIs
- **Data Sources**: Expenses from information providers
- **Compliance Checks**: Costs from regulatory and screening services

## How to Use

1. **Access**: Navigate to Admin → Cost Analysis
2. **Filter**: Use date ranges and filters to focus on specific periods
3. **Export**: Download cost reports for accounting and budgeting
4. **Optimize**: Identify high-cost tasks and optimize workflows

## Best Practices

- **Regular Monitoring**: Check costs weekly to identify unusual spikes
- **Budget Planning**: Use historical data to forecast future expenses
- **Workflow Optimization**: Review high-cost tasks for efficiency improvements
