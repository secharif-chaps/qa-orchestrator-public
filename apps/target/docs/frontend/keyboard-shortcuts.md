# List of keyboard shortcuts

This is the list of all specific keyboard shortcuts (excluding obvious ones such as Esc for closing dialogs or basic keyboard navigation).

| Page                       | Shortcut | Description                             |
| -------------------------- | -------- | --------------------------------------- |
| watch_files/[id]/documents | Ctrl+A   | Select all documents (same as checkbox) |
| watch_files/[id]/documents | Escape   | Close document detail panel             |
