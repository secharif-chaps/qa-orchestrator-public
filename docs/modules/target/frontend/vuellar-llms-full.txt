# Vuellar - Complete Component Reference

> Vuellar is Chapsvision's Vue 3 component library built with TypeScript, Tailwind CSS, and Reka UI. It provides a comprehensive set of accessible, dark-mode-ready UI components following atomic design principles.

---

## Installation

```bash
npm install @owlint/feathers-vue
```

## Usage

```vue
<script setup>
import { Button, Input, Avatar } from '@owlint/feathers-vue'
</script>

<template>
  <Button label="Click me" />
</template>
```

All components are exported from `@owlint/feathers-vue`. Import only what you need.

---

## Dark Mode

Dark mode is class-based. Add `dark` class to a parent element:

```vue
<div class="dark">
  <!-- All Vuellar components inside will use dark mode -->
  <Button label="Dark mode button" />
</div>
```

All components automatically adapt their colors for dark mode.

## Standardized Props Pattern

Most Vuellar components follow a standardized props convention:

### variant
Controls the visual style/weight of the component.
| Value | Description |
|-------|-------------|
| `primary` | Filled/solid background (default) |
| `secondary` | Lighter background or outlined |
| `tertiary` | Minimal/text-only (Button only) |

### intent
Semantic colors conveying meaning. Use for status, feedback, or actions with semantic significance.
| Value | Color | Use Case |
|-------|-------|----------|
| `neutral` | Gray | Default state, neutral information |
| `accent` | Pink | Branded elements, highlights |
| `success` | Green | Positive outcomes, confirmations |
| `warning` | Orange | Caution, attention needed |
| `danger` | Red | Errors, destructive actions |
| `info` | Blue | Informational messages |

### color
Decorative colors for visual variety without semantic meaning.
| Value | Description |
|-------|-------------|
| `sage` | Muted green-gray (primary brand color) |
| `almond` | Warm beige |
| `pink` | Soft pink |
| `indigo` | Deep purple-blue |
| `yellow` | Warm yellow |
| `cherry` | Deep red |
| `cyan` | Bright teal |

### size
Component dimensions. Availability varies by component.
| Value | Typical Use |
|-------|-------------|
| `xs` | Extra small, compact UIs |
| `sm` | Small, dense layouts |
| `md` | Medium, default size |
| `lg` | Large, prominent elements |

## Electrons (Core Primitives)

### Avatar

Displays a visual representation of a user, profile, or entity (person, group, company). Use inside other components (chips, list items) - not standalone. For clickable profile navigation, use Button instead.

**Props**:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | - | Display initials or text |
| `img` | `string` | - | Image URL for picture variant |
| `alt` | `string` | - | Alt text for image |
| `size` | `'lg' \| 'md' \| 'sm' \| 'xs'` | `'lg'` | Avatar size |
| `variant` | `'primary' \| 'secondary' \| 'picture'` | `'primary'` | Visual style |
| `intent` | `'neutral' \| 'accent' \| 'success' \| 'warning' \| 'danger' \| 'info'` | - | Semantic color |
| `color` | `'sage' \| 'almond' \| 'pink' \| 'indigo' \| 'yellow' \| 'cherry' \| 'cyan'` | - | Decorative color |

**Slots**:
- `default`: Custom content inside avatar

**Example**:
```vue
<script setup>
import { Avatar } from '@owlint/feathers-vue'
</script>

<template>
  <Avatar label="JD" size="md" intent="success" />
  <Avatar img="/user.jpg" alt="John Doe" variant="picture" />
</template>
```

### Button

Triggers immediate user actions (submit form, download file, open dialog, navigate). Use for primary interactions. For navigation links, prefer Link component instead.

**Props**:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | - | Button text |
| `icon` | `string` | - | Left icon (FontAwesome) |
| `iconRight` | `string` | - | Right icon |
| `iconLoading` | `string` | - | Loading state icon |
| `size` | `'lg' \| 'md' \| 'sm' \| 'xs'` | `'md'` | Button size |
| `variant` | `'primary' \| 'secondary' \| 'tertiary' \| 'accent'` | `'primary'` | Visual style |
| `loading` | `boolean` | `false` | Show loading state |
| `disabled` | `boolean` | `false` | Disable button |
| `block` | `boolean` | `false` | Full width |
| `fill` | `boolean` | `false` | Fill icon style |
| `as` | `string \| Component` | `'button'` | HTML element or component |
| `asChild` | `boolean` | `false` | Render as child element |

**Slots**:
- `default`: Custom content (overrides label)

**Events**:
- `click`: Emitted on click with MouseEvent

**Example**:
```vue
<script setup>
import { Button } from '@owlint/feathers-vue'
</script>

<template>
  <Button label="Submit" variant="primary" />
  <Button icon="fa-download" label="Download" variant="secondary" />
  <Button icon="fa-trash" variant="tertiary" />
</template>
```

### Checkbox

Enables multi-selection from a list of options. User can select zero, one, or multiple items. Use when choices are not mutually exclusive. For single choice, use Radio instead.

**Props**:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `id` | `string` | **required** | Unique identifier |
| `value` | `any` | - | Checkbox value |
| `label` | `string` | - | Label text |
| `name` | `string` | - | Form name |
| `disabled` | `boolean` | `false` | Disable checkbox |
| `labelPosition` | `'left' \| 'right' \| 'top-center' \| 'top-left' \| 'top-right' \| 'bottom-center' \| 'bottom-left' \| 'bottom-right'` | `'right'` | Label position |

**Model**: `v-model` binds to checked state or array of values

**Slots**:
- `default`: Custom label content

**Example**:
```vue
<script setup>
import { Checkbox } from '@owlint/feathers-vue'
import { ref } from 'vue'

const accepted = ref(false)
</script>

<template>
  <Checkbox id="terms" v-model="accepted" label="Accept terms" />
</template>
```

### Input

Single-line text field for user data entry. Supports various types (text, email, password, number, date). Use for short-form input. For multi-line text, use Textarea instead.

**Props**:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `id` | `string` | **required** | Unique identifier |
| `type` | `InputTypeHTMLAttribute` | `'text'` | Input type (text, email, password, number, date, etc.) |
| `label` | `string` | - | Label text |
| `placeholder` | `string` | - | Placeholder text |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Input size |
| `icon` | `string` | - | Left icon |
| `iconRight` | `string` | - | Right icon |
| `error` | `string` | - | Error message |
| `loading` | `boolean` | `false` | Loading state |
| `disabled` | `boolean` | `false` | Disable input |
| `readonly` | `boolean` | `false` | Read-only state |
| `required` | `boolean` | `false` | Required field |
| `min` | `number \| string` | - | Minimum value |
| `max` | `number \| string` | - | Maximum value |
| `minlength` | `number` | - | Minimum length |
| `maxlength` | `number` | - | Maximum length |
| `pattern` | `string` | - | Validation pattern |
| `autofocus` | `boolean` | `false` | Auto focus on mount |
| `disableValidation` | `boolean` | `false` | Disable built-in validation |

**Model**: `v-model` binds to input value

**Events**:
- `blur`, `input`, `change`, `focus`

**Exposed Methods**:
- `focus()`: Focus the input
- `blur()`: Blur the input

**Example**:
```vue
<script setup>
import { Input } from '@owlint/feathers-vue'
import { ref } from 'vue'

const email = ref('')
</script>

<template>
  <Input id="email" v-model="email" type="email" placeholder="you@example.com" />
  <Input id="search" v-model="query" icon="fa-search" placeholder="Search..." />
</template>
```

### Select

Dropdown menu for choosing from a predefined list of options. Use when options exceed 5-7 items or space is limited. Supports single or multiple selection, and grouped options.

**Props**:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `Array` | - | Array of options (exclusive with groups) |
| `groups` | `SelectGroup[]` | - | Grouped options (exclusive with options) |
| `icon` | `string` | - | Left icon in trigger |
| `placeholder` | `string` | - | Placeholder text |
| `disabled` | `boolean` | `false` | Disable select |
| `multiple` | `boolean` | `false` | Allow multiple selection |
| `loading` | `boolean` | `false` | Loading state |
| `preventScroll` | `boolean` | `false` | Prevent body scroll when open |

**Model**: `v-model` binds to selected value(s)

**Slots**:
- `default`: Custom trigger content
- `content`: Custom dropdown content
- `items`: Custom option items
- `groups`: Custom grouped items

**Events**:
- `select`: Emitted when option is selected

**Example**:
```vue
<script setup>
import { Select } from '@owlint/feathers-vue'
import { ref } from 'vue'

const country = ref('')
const countries = ['France', 'Germany', 'Spain', 'Italy']
</script>

<template>
  <Select v-model="country" :options="countries" placeholder="Select country" />
</template>
```

### Tab

Organizes related content into switchable panels within a limited space. Only one panel visible at a time. Use to reduce page length while keeping content accessible. Three variants: primary (bordered), secondary (underline), inner (minimal).

**Props**:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `tabs` | `NavigationTab[]` | - | Array of tab configurations |
| `variant` | `'primary' \| 'secondary' \| 'inner'` | `'primary'` | Visual style |

**NavigationTab Structure**:
```typescript
interface NavigationTab {
  id: string
  title: string
  isActive?: boolean
  disabled?: boolean
  icon?: string
  iconRight?: string
  badge?: string | number
  closable?: boolean
  click?: () => void
  onClose?: () => void
}
```

**Slots**:
- `default`: Custom tab items

**Example**:
```vue
<script setup>
import { Tab } from '@owlint/feathers-vue'
</script>

<template>
  <Tab :tabs="[
    { id: 'overview', title: 'Overview', isActive: true },
    { id: 'details', title: 'Details' },
    { id: 'settings', title: 'Settings', icon: 'fa-cog' }
  ]" variant="secondary" />
</template>
```

## Atoms (Building Blocks)

### Breadcrumb

Displays navigation hierarchy showing the user's current location within the site structure. Use for deep navigation structures to help users understand context and navigate back. Collapses middle items on overflow.

**Props**:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `Breadcrumb[]` | **required** | Array of breadcrumb items |
| `separatorIcon` | `string` | `'fa-chevron-right'` | Separator icon |
| `siblingCount` | `number` | `1` | Items shown before collapse |

**Breadcrumb Item Structure**:
```typescript
interface Breadcrumb {
  to?: string
  label: string
  icon?: string
  as?: Component | string
  group?: Breadcrumb[] // Hidden items shown in dropdown
}
```

**Slots**:
- `default`: Custom items
- `separator`: Custom separator

**Example**:
```vue
<script setup>
import { Breadcrumb } from '@owlint/feathers-vue'
</script>

<template>
  <Breadcrumb :items="[
    { label: 'Home', to: '/' },
    { label: 'Products', to: '/products' },
    { label: 'Category', to: '/products/category' },
    { label: 'Current Item' }
  ]" />
</template>
```

### Chips

Interactive tag-like element that can be removed or acted upon. Use for selected filters, tags in input fields, or removable items. Has close button by default. For static labels, use Tag instead.

**Props**:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | - | Chip text |
| `icon` | `string` | - | Left icon |
| `actionIcon` | `string` | `'fa-times'` | Close button icon |
| `size` | `'md' \| 'sm' \| 'xs'` | `'md'` | Chip size |
| `variant` | `'primary' \| 'secondary'` | `'primary'` | Visual style |
| `intent` | `'neutral' \| 'accent' \| 'success' \| 'warning' \| 'danger' \| 'info'` | - | Semantic color |
| `color` | `'sage' \| 'almond' \| 'pink' \| 'indigo' \| 'yellow' \| 'cherry' \| 'cyan'` | - | Decorative color |
| `as` | `string \| Component` | `'div'` | HTML element or component |
| `asChild` | `boolean` | `false` | Render as child element |

**Events**:
- `close`: Emitted when close button is clicked

**Slots**:
- `default`: Custom content
- `action`: Custom close button

**Example**:
```vue
<script setup>
import { Chips } from '@owlint/feathers-vue'

const removeTag = (tag) => { /* remove logic */ }
</script>

<template>
  <Chips label="Vue.js" @close="removeTag('vue')" />
  <Chips label="Important" intent="warning" @close="removeTag('important')" />
</template>
```

### Table

Displays structured data in rows and columns. Use for data-heavy interfaces requiring sorting, comparison, or scanning. Supports custom cell rendering, loading states, and responsive behavior.

**Props**:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `fields` | `TableField[]` | - | Column definitions |
| `items` | `Array` | - | Row data |
| `loading` | `boolean` | `false` | Show loading skeleton |
| `size` | `'lg' \| 'sm'` | `'sm'` | Table size |
| `skeletonRows` | `number` | `10` | Skeleton rows during loading |
| `scope` | `string` | `'col'` | Scope attribute for headers |

**TableField Structure**:
```typescript
interface TableField {
  key: string
  label: string
  hidden?: boolean
  span?: number
  class?: string
  header?: boolean
  format?: (value: any) => string
}
```

**Slots**:
- `default`: Entire table
- `colgroup`: Column definitions
- `header`: Header row
- `body`: Body rows
- `skeleton`: Custom loading state
- `footer`: Footer content
- `head({key})`: Custom header cell
- `cell({key})`: Custom cell content

**Example**:
```vue
<script setup>
import { Table, Tag } from '@owlint/feathers-vue'

const fields = [
  { key: 'name', label: 'Name' },
  { key: 'email', label: 'Email' },
  { key: 'status', label: 'Status' }
]
const users = [
  { id: 1, name: 'John', email: 'john@example.com', status: 'active' }
]
</script>

<template>
  <Table :fields="fields" :items="users">
    <template #cell(status)="{ value }">
      <Tag :label="value" :intent="value === 'active' ? 'success' : 'neutral'" />
    </template>
  </Table>
</template>
```

## Molecules (Functional Composites)

### Alert

Displays contextual feedback messages to users. Use for success confirmations, warnings, errors, or informational notices. Supports icon, title, description, and optional action button. Five variants: primary, info, success, warning, danger.

**Props**:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | - | Alert title |
| `description` | `string` | - | Alert description |
| `icon` | `string` | - | Left icon |
| `action` | `string` | - | Action button label |
| `loading` | `boolean` | `false` | Loading state for action |
| `showBackground` | `boolean` | `false` | Show background color |
| `variant` | `'primary' \| 'info' \| 'success' \| 'warning' \| 'danger'` | `'primary'` | Alert type |

**Events**:
- `click`: Emitted when action button is clicked

**Slots**:
- `default`: Entire content
- `title`: Custom title
- `description`: Custom description
- `action`: Custom action button

**Example**:
```vue
<script setup>
import { Alert } from '@owlint/feathers-vue'
</script>

<template>
  <Alert
    title="Success!"
    description="Your changes have been saved."
    variant="success"
    icon="fa-check"
  />
  <Alert
    title="Warning"
    description="This action cannot be undone."
    variant="warning"
    action="Proceed"
    @click="confirmAction"
  />
</template>
```

### Menu

Dropdown menu triggered by a button or element. Use for contextual actions, navigation options, or overflow menus. Supports keyboard navigation, disabled items, and custom positioning.

**Props**:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | - | Trigger button label |
| `items` | `MenuItem[]` | - | Menu items |
| `align` | `'start' \| 'center' \| 'end'` | `'start'` | Horizontal alignment |
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'bottom'` | Menu position |
| `disabled` | `boolean` | `false` | Disable menu |
| `modal` | `boolean` | `true` | Block outside interaction |
| `showArrow` | `boolean` | `false` | Show arrow pointer |
| `sideOffset` | `number` | `4` | Distance from trigger |

**Model**: `v-model` binds to open state (required)

**MenuItem Structure**:
```typescript
interface MenuItem {
  label: string
  disabled?: boolean
  onClick?: () => void
}
```

**Slots**:
- `trigger`: Custom trigger element
- `content`: Custom dropdown content
- `items`: Custom item rendering
- `item`: Custom single item

**Example**:
```vue
<script setup>
import { Menu } from '@owlint/feathers-vue'
import { ref } from 'vue'

const isOpen = ref(false)
</script>

<template>
  <Menu v-model="isOpen" label="Actions" :items="[
    { label: 'Edit', onClick: () => edit() },
    { label: 'Duplicate', onClick: () => duplicate() },
    { label: 'Delete', onClick: () => deleteItem() }
  ]" />
</template>
```

## Organisms (Complex Composites)

### Modal

Overlay dialog that requires user attention or action. Use for confirmations, forms, or focused tasks that interrupt the main flow. Supports stacking, custom sizes, and accessible focus management. Close via button, escape key, or clicking outside.

**Props**:
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `displayModal` | `boolean` | **required** | Modal visibility (v-model) |
| `title` | `string` | - | Modal title |
| `description` | `string` | - | Modal description |
| `icon` | `string` | - | Title icon |
| `iconClose` | `string` | `'fa-times'` | Close button icon |
| `size` | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl'` | `'md'` | Modal width |
| `content` | `boolean` | `false` | Content-only mode (hides footer) |

**Events**:
- `close`: Emitted when modal should close

**Slots**:
- `default`: Entire modal content
- `title`: Custom title
- `description`: Custom description
- `footer`: Custom footer
- `action`: Custom action area

**Example**:
```vue
<script setup>
import { Modal, Button } from '@owlint/feathers-vue'
import { ref } from 'vue'

const showModal = ref(false)
</script>

<template>
  <Button label="Open Modal" @click="showModal = true" />

  <Modal v-model:displayModal="showModal" title="Confirm Delete" @close="showModal = false">
    <template #description>
      Are you sure you want to delete this item?
    </template>
    <template #footer>
      <Button label="Cancel" variant="secondary" @click="showModal = false" />
      <Button label="Delete" variant="primary" @click="deleteItem" />
    </template>
  </Modal>
</template>
```

## Deprecated Components

### Indicator
**Status**: DEPRECATED - Use `Bullet` instead.

The Indicator component is deprecated and will be removed in v1.0. Migrate to the Bullet component which provides the same functionality with the standardized props pattern.

### ToggleGroup
**Status**: DEPRECATED - Use `Toggle` instead.

The ToggleGroup component is deprecated and will be removed in v1.0. Migrate to the Toggle component which provides enhanced functionality with the standardized props pattern.

## Best Practices

### When to Use Each Component

| Need | Use | Not |
|------|-----|-----|
| Navigate to another page | `Link` | `Button` |
| Trigger an action | `Button` | `Link` |
| Select multiple options | `Checkbox` | `Radio` |
| Select one option | `Radio` | `Checkbox` |
| Toggle immediate setting | `Switch` | `Checkbox` |
| Form boolean choice | `Checkbox` | `Switch` |
| Static category label | `Tag` | `Chips` |
| Removable filter/tag | `Chips` | `Tag` |
| Status dot only | `Bullet` | `Badge` |
| Status with text/icon | `Badge` | `Bullet` |
| Short text input | `Input` | `Textarea` |
| Long text input | `Textarea` | `Input` |
| 5+ dropdown options | `Select` | `Radio` |
| 2-4 visible options | `Radio` | `Select` |
| View mode toggle | `Toggle` | `Tab` |
| Content sections | `Tab` | `Toggle` |

### Intent vs Color

- Use **intent** for semantic meaning (success, error, warning states)
- Use **color** for decorative purposes (visual variety without meaning)
- When both are provided, **intent takes precedence**
