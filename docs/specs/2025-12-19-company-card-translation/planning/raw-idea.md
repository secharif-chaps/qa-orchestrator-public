# Raw Idea: Company Card Translation

## Feature Description

Add the ability to translate company card data into multiple languages (French, German, Spanish, Italian, Portuguese, Dutch). Users can select a language from a dropdown on the company card page. Translations are performed on-demand using Systran API. The system should display original English data by default, with translations stored alongside original values. This feature requires a prerequisite refactoring of the SourcedValue type system to embed translations directly into the data structure.
